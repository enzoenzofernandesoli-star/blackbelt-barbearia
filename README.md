# Black Belt Barbearia

Site conceitual responsivo desenvolvido com React, TypeScript e Vite para a Black Belt Barbearia, em Santos.

## Direção visual

- Conceito: dojo urbano — disciplina do jiu-jitsu aplicada ao cuidado masculino.
- Paleta: preto carvão, branco faixa e vermelho graduação.
- Tipografia: Barlow Condensed para impacto; Manrope para leitura.
- Movimento: não utiliza animações, conforme o escopo do projeto.

## Conteúdo e fontes

Os dados do negócio ficam centralizados em `src/data/barbearia.ts`.

- Google Maps: nome, endereço, telefone, horários, avaliação e depoimentos públicos.
- Cashbarber: manifesto, programa de assinaturas e fotografias do estabelecimento.
- Instagram: link oficial informado na ficha do Google Maps.

As fotografias são servidas localmente. Não existe hotlink.

## Desenvolvimento

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
```
